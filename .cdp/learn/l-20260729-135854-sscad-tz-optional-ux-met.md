## Learning
Developer receiving the automation card needs optional **UX metaphors & expectations** — the *conclusions* CustDev usually yields, not a full CustDev report in the TZ.

- Why: even if author/dev lives in the same САПР kettle, the template is incomplete without «how the user actually thinks/acts» when that context is missing or uneven across the team.
- Form: optional section (skip if both sides already share the craft); concentrated bullets — metaphors, expected flow, pain moments, what «done» feels like in the UI — not interview transcripts or persona essays.
- Anti: full CustDev dump, research methodology, endless journey maps.
