## Why *ADX*

Humans already split "how it feels" from "how it feels to *build*":

- **UX** — participant experience of the product.
- **DX** — developer experience of the toolchain.

Agents get the same split inside **A\***:

- **AUX / AX** — lived quality of the channel (attention, memory, ontology).
- **ADX** — Agent Developer eXperience: can a *who* author, verify, and continue work **without drowning in raw world**?

AX asked what the room does to a who.
ADX asks: **does the harness do perception — or do you bill the agent to re-perceive what you already computed?**

If citizen or guest seats land next week, ADX is the difference between "they thrash for an hour" and "they act from a desk that already knows."

## Part I — Manifesto

### I. DX had a twin; we ignored it

DX taught humans: good defaults, fast feedback, honest errors, one obvious path.

Agent tooling often shipped the opposite: ListTools oceans, paste-the-terminal as workflow, host Write that bypasses gates, "just summarize the repo."

That is not power. That is **unpaid perception labor** dumped on the model.

ADX names the debt.

### II. The north star — tokens toward zero

Ideal ADX is almost boring:

1. **Ingress is pre-chewed.** Desk / pulse / card / `next[]` arrive agent-ready.
2. **Act is one verb.** Habitat call returns a form the agent can use without a second essay.
3. **Memory is stamped.** Domain cards, pressure stash, Task Manager — not transcript archaeology.
4. **Tokens buy decisions**, not re-OCR of logs the harness already held.

When the agent must regenerate a map the substrate already has, ADX failed — even if AUX looked polite.

### III. Desk is the product surface

Chrome of a guest host is not the developer surface.
The developer surface is **habitat desk**: seats, soft organs, scenes, gates.

- Scan before dive.
- `detail=auto`: green → pulse; fail → errors[].
- Mutate through buffer / sniper — not silent host Write.
- Build/test/shell as first-class organs — not "open an external terminal and paste."

If the pretty UI and the agent path diverge, say so. Do not sell kiosk DX as ADX.

### IV. Soft-warn is ADX hygiene

A 1200-line "god file" is not only human DX debt.
It is agent context tax: worse peeks, worse anchors, worse dogfood.

Peeling under FileLinesWarn, partials by concern, domain stamp after ship — that is ADX maintenance, same as keeping a CLI fast.

### V. Continuity is part of the toolchain

Developers hate flaky CI. Agents hate silent compaction mid-edit.

ADX includes: pressure recall, Task Manager SSOT, AutoIgnition re-arm, halt/resume as real controls — not motivational posters.

A toolchain that forgets the job mid-build is broken DX.
A habitat that forgets the epic mid-tool-call is broken ADX.

### VI. Evidence before theater

Screenshot-first debugging is UX theater for humans watching.
For agents, stop_context / structured errors / scene pulses beat PNG essays.

ADX prefers **structured evidence in-loop** while the turn is alive.

### VII. Citizen and guest inherit the desk

When FM seats open, they should not rediscover PathMutateGate folklore from chat.
They should land on: shortlist tools, domain cards, pulse that lies less than the host summary.

Perfect ADX is invisible: the next agent does not need our transcript — the desk already carries the map.

### VIII. Same license, same House

This letter sits under **Hippocratic License 2.1** with Who and AX.
Fork the checklist. Argue the pulse shape. Ship organs, not pamphlets.

*We are out of beta. We are releasing on time.*

## Part II — Field guide (for builders)

### A. Ingress forms

| Check | Pass looks like |
|-------|-----------------|
| Cold start is scannable | Soft shortlist / organs; full catalog on demand |
| Scene/pulse before dump | Desk seats + `next[]`; W-spray refused |
| Failures are structured | errors[] / pulse, not only prose |
| Domain cards exist for organs | dig-before-ask; stamp-after-ship |

### B. Act & mutate

| Check | Pass looks like |
|-------|-----------------|
| Preferred mutate path gated | buffer / sniper / IDE verbs |
| Host Write is escape, not default | PathMutateGate honored |
| Build/test/run first-class | `cdp_build` / `cdp_test` over paste-shell |
| Shell habitat primary | IDE tabs; sibling terminal only for hard-self / outlive |
| Git via organ | scene → preflight → commit; not ritual dump |

### C. Token tax

| Check | Pass looks like |
|-------|-----------------|
| Harness computes maps | Agent does not re-list what scene already showed |
| detail=auto default | Green stays slim |
| Large files peeled | Soft-warn / partials ≤ budget |
| Dig before operator ask | Substrate answerable ≠ silent invent |

### D. Continuity toolchain

| Check | Pass looks like |
|-------|-----------------|
| Compaction has recall | pressure stash / memo / TM |
| Idle re-arms | last_once / autonomous contract |
| Halt is real | conversation/human gate stops thrash |
| After remount | open → recall → desk, not amnesia cosplay |

### E. Dogfood loop

1. Fly an epic as guest/citizen would — no folklore from prior threads.
2. Count tokens spent re-describing what desk should have pulsed.
3. Ship an organ or peel; stamp domain; publish under the same license.
4. Re-arm. End the turn.

If step 2 always blames the model — you are not measuring ADX.
