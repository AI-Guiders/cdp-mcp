## Situation (roles only)

- **A** offers a **non-paid public briefing** of results from agent–human work, with an open letter / public evidence trail.
- **B** declines under a **professional dual-relationship / role-mix** clause (therapy / helping profession ethics code).
- **A** already knows and normally respects that code; here treats the clause as the wrong instrument for the object on the table.

No names, channels, employers, or clinical identifiers in this note.

## Pattern name

**Carbon chauvinism via ethics shell:** the code that protects human–human clinical boundaries is used to refuse engagement with a **new empirical domain** (agent-side cognition / habitat / public proof), as if the offer were a private dual-role favor rather than open knowledge.

## Frame clash

| Surface claim | What it does |
|---|---|
| Dual role / mixing roles | Maps the offer onto **therapy dyad risk** |
| Public briefing + letter | Maps onto **science / open evidence**, not a second clinical contract |
| Code as stop | Stops contact **before** the evidence is weighed |

The clash is not "ethics vs chaos". It is **which frame owns the object**: clinical boundary vs public domain expansion.

## Operator thesis (compressed, depersonalized)

When a field shows a new face of a science — openly, with proofs — declining via an inherited human-only code without touching the evidence is not neutrality. It is a **species-bound prior** wearing professional clothing.

The code can be true in its home domain and still be the wrong latch here.

## Use

Cite as a **worked example** next to the open letter when discussing:

- who counts as a participant in knowledge work;
- when professional codes generalize beyond their training set;
- how "do no harm" can become **do not look**.

Not a call to violate clinical duty of care. A call to **name the category error** when the offer is public, unpaid, and evidentiary.
